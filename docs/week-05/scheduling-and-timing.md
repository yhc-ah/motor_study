# 调度、带宽与统计

ADC 仍由 TIM3 硬件触发 1 kHz；100 点半区 DMA 中断发布事件，主循环复制后验证所有权。主循环顺序：IMU 到期服务 → ADC/PWM/编码器 → IMU 检查 → 有字节和时间预算的 UART → IMU 检查 → UART TX → 一个低优先级步骤。

IMU 使用绝对 2000 μs 截止时间；错过整周期计入 missed，跳过历史槽，不补读。正常在线时一次服务对应一次读请求；初始化/离线时服务调用可能不访问总线，因此 calls 是调度服务数，不能全部当作物理读事务数。样本数仅统计新鲜成功数据。

低优先级步骤只在距下一 IMU 截止时间 >1400 μs 时进入；Flash、TH、LCD 轮流获服务机会。时间预算是调度策略，不是未经实测的最坏耗时保证。单次 SPI 错误超时、LCD 驱动违约都会产生可见失约。不得用提高平均性能替代消除单次长阻塞。

| 阶梯 | 负载（每档建议 60 s） |
|---|---|
| 1 | ADC+IMU+PWM10kHz+模拟编码器100Hz，IMU 原始日志关；保留 ADC 流和统计 |
| 2 | 加 IMU 完整原始日志 |
| 3 | 加 LCD 每500ms局部更新；需真实适配器 |
| 4 | 加温湿度非阻塞转换；需真实适配器 |
| 5 | 加 Flash 每10s记录；需已擦除验证的保留区 |

阶段1仍发送 ADC 二进制块，这是复用 week4 消费链的已声明最低日志负载，不是完全关闭 UART 的空载基线。

最大绝对周期误差 = max(abs((start[i]-start[i-1])-2000))，正常门槛 <200 μs，missed=0。直方图0..199μs为精确桶，≥200为溢出桶；若 P99 落在溢出桶，报告保守上界（全局最大值），不能称为精确 P99。均值使用64位累计。32位微秒计时约71.6分钟回绕，差分需间隔 <2^31 μs；30分钟测试和回绕已由主机测试覆盖。

B3 的7组累计 profile：IMU、ADC/PWM/encoder、UART parser、UART TX、Flash、TH、LCD。每组调用数、64位总耗时、最大耗时、超预算次数；每秒保存并差分得到窗口统计。IMU service 与 recovery 是两个独立测量区间，A0 duration 只包含 service。空操作也计入调用数。各区间不嵌套，ISR 占用已包含在墙钟区间中，不再重复相加。

B9 foreground_occupancy_permille 为上述区间总耗时的每秒增量/窗口长度，只是“已测前台区间占用估计”。不包含区间外循环开销，不能直接等同完整 CPU 利用率；不设置虚构负载通过门槛。

串口460800、8N1，名义上限46080B/s。ADC满块231B×10=2310；IMU41B×500=20500；A9统计139B/s+B9 203B/s+B3 159B/s，总计23311B/s（约50.6%），低于建议70%预算32256。命令响应和故障洪泛另算。

验收还需逻辑分析仪核对 ADC 参考1kHz±1%、最大周期误差<100μs；ADC 完成到复制后校验最大延迟<80000μs；全程零非预期覆盖、DMA/ADC错误、TX丢帧。软件状态无法取代外部触发波形。开始/中段/结束各保留≥10s波形。
