# F407 / F411 资源与接线

F407 延续 week4 引脚与初始化所有权，CubeMX 文件没有伪装成已生成这些手写外设。重新生成后应核对主循环入口与中断转发并重新构建。

| 用途 | F407 | F411 |
|---|---|---|
| 时钟 | 原工程168MHz；APB1计时器84MHz | HSI→PLL96MHz；APB1计时器96MHz |
| 微秒计时 | TIM2 PSC83 | TIM2 PSC95 |
| UART460800 | USART1 PA9/10，RX DMA2Stream2CH4，TX Stream7CH4 | USART1 PA9/10，TXE IRQ，1024B整帧队列；不实现RX命令 |
| MPU6050 | I2C1 PB8/9，400kHz，外部上拉 | 同引脚I2C1，400kHz，外部上拉 |
| I2C测量探针 | PC5 | 直接观察SCL或A0时间戳；未指定额外板载引脚 |
| ADC | PC0/ADC1_IN10，DMA2Stream0CH0 | 本周不移植 |
| ADC触发参考 | PA6/TIM3_CH1，1kHz | — |
| DMA处理探针 | PC2 | — |
| PWM输出 | PB6/TIM4_CH1，10kHz | — |
| 模拟编码器输出→输入 | PG2→PC6、PG3→PC7；TIM6发生器→TIM8计数器 | — |
| Flash | SPI1 PB3/4/5、PG6片选 | 本周不移植 |
| SWD | 保留原SWD引脚 | PA13/14，保留SWD |
| LCD/温湿度 | 型号、连接、已有驱动待提供 | 本周不移植 |

ADC 输入只接0..3.3V电位器，外设共地。断电后把同一个MPU6050从F407移到F411，不连接两个主机到同一未设计的I2C总线。F411实际板型、供电、丝印和接线需核对；使用HSI避免猜测外部晶振，仍需实测时钟误差。

Flash 仅接受显式指定的、4KiB对齐的20480字节空闲区域：前16384字节放最多256条64B日志，末4096字节专供后台擦除。30分钟180条=11520字节，预留足够。不得在未知地址进行擦写；程序没有默认擦除地址。
