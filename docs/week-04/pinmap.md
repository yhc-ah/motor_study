# 第四周接线与资源

本配置是明确的外接实验方案，不代表已经核对你板上所有跳帽、LCD 或其他模块连接。用户确认前三周已完成；第四周实际接线与实测尚未取得。断电核对原理图、引出排针及负载后再接线。仅3.3V信号，仪器共地，不接电机动力级。

| 信号 | STM32F407ZG 引脚/功能 | 接线 |
|---|---|---|
| PWM_OUT | PB6，AF2 TIM4_CH1 | 接逻辑分析仪，不接电机 |
| ENC_A_IN | PC6，AF3 TIM8_CH1 | 接 PG2 |
| ENC_B_IN | PC7，AF3 TIM8_CH2 | 接 PG3 |
| SIM_A_OUT | PG2，推挽输出 | 仅接 PC6 与分析仪 |
| SIM_B_OUT | PG3，推挽输出 | 仅接 PC7 与分析仪 |
| ADC_IN | PC0，ADC1_IN10 | 外接10kΩ电位器中点 |
| 电位器两端 | 3.3V / GND | 与板载电位器二选一，避免两个信号源并接 |
| DMA_PROBE | PC2，推挽输出 | 每个HT/TC回调短高脉冲，接分析仪 |
| TRIGGER_REF | PA6，AF2 TIM3_CH1 | 1kHz参考PWM，其上升沿与更新周期对应；不是ADC采样保持的直接测量 |
| UART | PA9/PA10，USART1 | 沿用J80/J81及已验证USB-UART，460800 8N1 |
| 心跳 | PF8 蓝灯 | 每500ms翻转 |

TIM2保留1MHz自由运行计数，不分配给ADC。PA1保留原串口/按键探针。I2C1 PB8/PB9、SPI1 PB3/PB4/PB5和PG6保持week3资源，但第四周默认不运行传感器任务，也不擦写Flash。

如果屏幕/扩展模块占用以上引脚，先解除其连接或修改 `bsp/week4/bsp_week4.c` 的完整复用配置与资源文档；仅改一个GPIO宏不能自动改变定时器通道。无空闲引脚时不得把两个输出短接。

启动后PWM保持PB6推挽低电平，A/B发生器为00，ADC/DMA及发生器等待命令启动。PC2只测回调宽度及间隔，不能用其10Hz块事件当作1kHz采样波形。
